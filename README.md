# Bed Stuy Community Maps

An interactive mapping project connecting Bedford-Stuyvesant residents with local block associations and community resources.

## Live Site

Visit the live site: [your-github-username.github.io/block_associations](https://your-github-username.github.io/block_associations)

## About This Project

This project provides an interactive map interface to help residents of Bedford-Stuyvesant:
- Locate and connect with their local block association
- Find contact information and meeting schedules
- Submit new block association information via Google Form

## Features

### Current Maps
- **Block Associations Map** - Interactive Mapbox map showing block association boundaries with searchable street names

### Coming Soon
- **Block Parties Map** - Upcoming community events and celebrations
- **Community Resources Map** - Essential services, health centers, and local resources

## Technology Stack

- **Mapbox GL JS** - Interactive mapping
- **HTML/CSS/JavaScript** - Frontend
- **Google Forms** - Community data submission
- **GitHub Pages** - Hosting
