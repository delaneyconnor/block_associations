About This Map

This is an interactive map designed to help residents of Bedford-Stuyvesant locate and connect with block associations.

How to use this map:

• Click on any street segment on the map to view the block association information

• Use the search box to find your street by name

• Contact information and meeting schedules are displayed when available

If you notice any missing or incorrect information, please use the "Add Your Association" button to help us improve this resource.

This map is a work in progress. If you'd like to contribute to provide feedback or ideas, contact delaneyconnor1@gmail.com
